Windows 桌面版首发：下载 EXE 即可配置和运行，无需安装 Python、手改 JSON 或敲命令。

## 下载与使用

推荐下载 `yuketang-ocr-assistant-v0.2.0-windows-x64.zip`，解压后双击
`YuketangAssistant.exe`。在窗口中配置模型 → 扫码登录 → 开始监控。
也提供独立 EXE；Windows ZIP 另含使用说明和第三方许可证。

- 提供方预设和自定义 API 地址/模型，包括华为云 MaaS。
- 密钥隐藏输入，图形化保存配置和测试连接。
- 支持浏览器模式、HTTP 模式、时长、时间窗及开始/停止任务。
- 内置不调用模型的本地演示，使用独立测试数据目录。
- 更新 EXE 后保留用户目录内的配置和登录态。

运行环境：Windows 10/11 x64，已安装 Microsoft Edge。图片题依赖 Windows OCR。
默认仅显示参考答案；自动填选和自动提交需显式开启。
附件不包含密钥、课堂登录态和个人运行记录。

详细使用方法见 [桌面版文档](https://github.com/yanami-namida/yuketang-ocr-assistant/blob/main/docs/desktop.md)。
