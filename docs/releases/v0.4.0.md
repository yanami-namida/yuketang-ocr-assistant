# v0.4.0 — 只读版

这一版把项目收敛回「第二双眼睛」：只识别题目、只给参考答案，不再替使用者操作页面。

## 移除

- 自动作答：删除 `--auto-fill` / `--auto-submit` 及对应的配置键（`auto_fill`、
  `auto_submit`、`min_confidence`、`auto_retry_limit`、`auto_retry_gap`、`fill_gap`、
  `submit_delay`），代码中不再有点击选项或点击提交的路径。
- HTTP 后台版：删除 `ykt_http.py`、`ykt_api.py`、`ykt_http_menu.py`、
  `README_HTTP.md`、`requirements-http.txt`、`config.http.example.json`、`tests/test_http.py`
  及对应的启动器，项目不再直接调用平台收题/答题接口。
- 桌面版的“HTTP 模式”“浏览器自动填选项”“自动提交答案”开关；界面只保留时长、
  时间窗与图片题方式。
- 第三方说明中的协议参考段落；`websocket-client` 依赖随 HTTP 版一并移除。

## 保留

- 浏览器识题、视觉/OCR 双路、浮层、答案缓存、提示音、调试快照。
- 只读的 `GET /api/v3/classroom/on-lesson` 导航（自动打开正在上的课，不签到）。
- 桌面版扫码登录、模型配置、连接测试、定时监控。

## 文档

- 新增 [可接受使用政策](ACCEPTABLE_USE.md)，说明非官方、只读、禁止代答与批量刷课。
- README、架构说明、桌面版说明、安全说明、贡献指南同步改为只读表述。
- 更新测试：移除自动作答用例，新增「识别结果不会产生点击」的只读断言。

## 升级提示

旧配置文件里的自动作答键会被忽略，可以手动删除。若你依赖过 HTTP 后台版或自动提交，
请留在旧版本自行评估合规性；本项目不再提供这些能力。
